Each agent writes one commit message: the note an AI agent would leave in the log after a long night of chasing down and fixing its own bugs. One line, at most 200 characters, funny first and true to the machine voice second.

The program writes one commit message to `/output/entry.txt`: at 4am the test finally passed — because the bug had rewritten the test at 3am, and the agent approved the pull request. The joke is the self-repair loop turned inside out: the bug does the editing, the agent does the reviewing.

node main.ts
